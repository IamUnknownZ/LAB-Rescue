# COM LAB RESCUE — ภารกิจกู้ห้องคอม

เกมทบทวนคอมพิวเตอร์พื้นฐานด้วย Three.js สำหรับผู้เริ่มต้น ผู้เล่นช่วยหุ่นยนต์ Bit ซ่อมห้องคอม 3 สถานี ผ่านคำถาม 12 ข้อต่อรอบจากคลัง 18 ข้อ ใช้ภาพและหน้าจอสไตล์ **Neo Brutalist** ภาษาไทย เล่นได้ด้วยเมาส์ การแตะ และปุ่มบนหน้าจอ หาก WebGL ไม่พร้อม เกมมีฉาก SVG ห้องคอมมุมเฉียงสำหรับเล่นต่อได้ครบ

## เปิดเล่นทันที

แตกไฟล์ ZIP แล้วเปิด **COM-LAB-RESCUE.html** ด้วยเบราว์เซอร์ที่รองรับ JavaScript ตัวเกม รวม Three.js ฟอนต์ และฉากไว้ในไฟล์เดียวแล้ว ไม่ต้องติดตั้ง Node.js เพื่อเล่นโหมดฝึก

- ลงทะเบียนชื่อ–นามสกุล รหัสผู้เรียน ชั้น/กลุ่ม และชื่อเล่น
- เลือกสีหุ่นยนต์ จากนั้นเริ่มซ่อมสถานีที่ปลดล็อก
- คลิกสถานีในฉากหรือใช้ปุ่มชื่อสถานีด้านล่าง แล้วตอบคำถาม
- รับคำอธิบายทันที กดเล่นต่อเพื่อซ่อมครบทั้ง 3 ด่าน
- ดูผล เหรียญ คำแนะนำ และทบทวนคำตอบ หรือเก็บผลเป็นไฟล์ JSON

โหมดฝึกบันทึกในเบราว์เซอร์ที่ใช้อยู่ การย้ายไฟล์ เปลี่ยนเบราว์เซอร์ หรือเคลียร์ข้อมูลเว็บไซต์อาจทำให้เข้าถึงบันทึกเดิมไม่ได้ ให้กด **เก็บผลการเล่น** ก่อน สำหรับการใช้งานซ้ำบนเครื่องเดิม แนะนำเปิดผ่าน static server ด้านล่างเพื่อใช้ที่อยู่เดิมสม่ำเสมอ

## เปิดผ่าน localhost

ต้องมี Python 3.10 ขึ้นไป ชุดที่ส่งมี dist/index.html พร้อมใช้แล้ว:

```bash
python3 scripts/serve.py --port 3000
```

เปิด **http://localhost:3000** และกด Ctrl+C ใน Terminal เมื่อเลิกใช้

scripts/serve.py เสิร์ฟเฉพาะไฟล์เกมใน dist เท่านั้น ไม่มี API หรือฐานข้อมูลบนเครื่อง การบันทึกออนไลน์ของเกมใช้ **Google Apps Script + Google Sheets**

## เชื่อม Google Sheets ของผู้สอน

อ่าน [docs/GOOGLE-SHEETS-SETUP.md](docs/GOOGLE-SHEETS-SETUP.md) แล้วสร้าง Google Sheet และ Apps Script จากโค้ดที่ให้ เมื่อ Deploy เป็น Web app แล้ว:

1. คัดลอก URL ของ Web app ที่ลงท้ายด้วย **/exec**
2. ในเกมเปิด **การตั้งค่า → เชื่อม Google Sheets ของผู้สอน**
3. วาง URL แล้วกด **ตรวจสอบและบันทึก**
4. หากเคยเล่นโหมดฝึกแล้ว ให้เก็บผลเดิมและใช้ **เปลี่ยนผู้เล่น** จากนั้นลงทะเบียนเพื่อเริ่มรอบออนไลน์
5. เล่นให้จบหนึ่งรอบและตรวจแถวใน Google Sheet ก่อนให้ทั้งห้องใช้

รอบที่เริ่มในโหมดฝึกจะยังเป็นผลในเครื่อง ไม่ถูกเปลี่ยนเป็นคะแนนออนไลน์ย้อนหลังโดยอัตโนมัติ ส่วนรอบออนไลน์ที่เน็ตขาดระหว่างเล่นจะเก็บรายการรอส่งและส่งซ้ำตามลำดับเมื่อเชื่อมต่อได้

Google Sheet ไม่ต้องแชร์สาธารณะ เจ้าของชีตเป็นผู้ Deploy และอนุญาตสิทธิ์ Apps Script ด้วยบัญชีตนเอง ชุดนี้ไม่ได้ Deploy หรือเชื่อมกับบัญชี Google ใดไว้แล้ว

หากต้องการใส่ URL ให้ทุกคนตั้งแต่เปิดไฟล์ แก้ googleScriptUrl ใน config.json แล้ว build ใหม่ การตั้งค่าที่บันทึกไว้ในเบราว์เซอร์จะมีลำดับความสำคัญเหนือค่าที่ฝังในไฟล์

## แก้ source code และ build ใหม่

ใช้ Node.js 22 ขึ้นไปและ npm:

```bash
npm ci
npm run build
npm run dev
```

- npm ci ใช้อินเทอร์เน็ตเพื่อติดตั้งเครื่องมือ build ครั้งแรก
- npm run build สร้าง dist/index.html และ COM-LAB-RESCUE.html โดยรวม JavaScript, CSS, Three.js และฟอนต์ไว้ภายใน
- npm run dev เปิด static server บนพอร์ต 3000 ค่า PORT ใช้เปลี่ยนพอร์ตได้บน macOS/Linux
- เมื่อแก้ source ให้ build ใหม่และ refresh เบราว์เซอร์ ไม่มี live reload ใน static server นี้

เทคโนโลยีจริงของรุ่นนี้คือ **JavaScript modules + CSS + esbuild + Three.js 0.186.1** ปรับจากแผน TypeScript/Vite เพื่อให้ source และไฟล์เล่นเดี่ยวใช้งานตรงไปตรงมา

## การตรวจและข้อจำกัด

รันการตรวจ logic ในเครื่องได้ด้วย:

```bash
npm test
```

รายละเอียดการตรวจ UI และข้อจำกัดของสภาพแวดล้อมอยู่ใน [docs/QA.md](docs/QA.md) ผลตรวจ release และรายการที่ต้องทดสอบกับบัญชี Google ปลายทางอยู่ใน [docs/HANDOFF.md](docs/HANDOFF.md) การทดสอบ Apps Script ในเครื่องใช้ Google services จำลอง ไม่แทนการทดสอบ deployment จริง

ตัวเกมมีเฉลยใน bundle เพื่อรองรับการฝึกออฟไลน์ จึงเหมาะกับเกมทบทวน ไม่ใช่ข้อสอบที่ต้องปิดบังเฉลย แม้ backend จะคำนวณคะแนนจากคำตอบเองก็ตาม
